# Security Policy

## Supported Versions
Security updates are actively applied to the default branch (`main`).

## Reporting a Vulnerability
To report a security vulnerability or critical disclosure:
1. Please open a Private Vulnerability Advisory on GitHub or contact the maintainer directly.
2. Provide details of the finding, proof-of-concept steps, and affected components.
3. Coordinated vulnerability disclosure timelines follow industry-standard 90-day windows.
